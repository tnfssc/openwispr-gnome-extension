# This repository has moved

> **Deprecated:** OpenWispr development, releases, documentation, and issue tracking now live in the [OpenWispr monorepo](https://github.com/tnfssc/OpenWispr).

The GNOME Shell extension and its Linux companion are now maintained at [apps/gnome](https://github.com/tnfssc/OpenWispr/tree/develop/apps/gnome).

No new pull requests, issues, or releases will be accepted here. This repository is archived as a read-only historical reference; existing releases remain available. Please use the canonical repository for support and contributions.

The GNOME component continues to be available under the MIT License in the canonical repository.
